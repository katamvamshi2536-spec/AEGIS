# Contributing to PolicyMesh

Thank you for your interest in contributing to **PolicyMesh**!

## Code of Conduct
We are committed to providing a welcoming and inspiring community for all contributors.

## How to Contribute
1. Fork and clone the repository.
2. Create a virtual environment and install dev dependencies:
   ```bash
   pip install -e .[dev]
   ```
3. Create a feature branch (`git checkout -b feature/dynamic-quorum-policies`).
4. Write clean code adhering to PEP 8 standards with strict type annotations.
5. Add unit tests in `tests/test_policymesh.py`.
6. Run `pytest` and verify all tests pass.
7. Open a Pull Request with a clear explanation of your changes.
